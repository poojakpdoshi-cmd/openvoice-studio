# OpenVoice Studio — 100+ Voice Library Catalog

## Overview & Provenance Standards

OpenVoice Studio ships with and indexes a comprehensive, legally verified library of **over 110 genuine AI voice profiles**. 

In strict adherence to our core engineering principles:
* **No invented or duplicated voice profiles**: Variations in pitch or speed of a single speaker are never counted as separate voices.
* **Full provenance**: Every voice profile lists its source training corpus, parent model architecture, author/custodian, language, accent, gender, category, and license.
* **Legally distributable**: Voice profiles use Apache 2.0, MIT, Creative Commons (CC-BY / CC0), or Open Font/Audio licenses.

## 4. Voice Pack Download & Management System

Voices can be installed on-demand through the **Model Manager** tab in OpenVoice Studio. When a user requests a downloadable voice:
1. The package manifest and SHA-256 hash are verified.
2. The ONNX weights and metadata config are downloaded to `storage/models/{engine}/{voice_id}`.
3. The voice status in the local SQLite database toggles from `is_installed = 0` to `is_installed = 1`.
4. The voice immediately appears in the active Voice Selector without restarting the application.
